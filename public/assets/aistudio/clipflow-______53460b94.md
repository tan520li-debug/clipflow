# ClipFlow 修改提示词（按优先级，一次贴一条进 Google AI Studio）

## 1. 接口加固（最重要）
请加固现有的 Express API，不要改产品功能本身。
1. 所有 /api/*（/api/health 除外）必须先经过鉴权中间件：支持环境变量 ADMIN_ACCESS_TOKEN（请求头 x-clipflow-token），以及可选的简单登录会话（邮箱+密码，密码哈希存在服务端）。没有令牌时返回 401。
2. 给每个 IP 和每个用户加速率限制：普通接口每分钟最多 20 次，Veo/TTS/voice-clone 每分钟最多 3 次。超过返回 429。
3. 在服务端记录每次 Gemini/TTS/Veo 调用的大约 token/秒数消耗，在前端顶栏显示「本会话已用额度」，并设置每日上限（可用环境变量）。
4. 500 错误只返回友好中文提示，不要把原始 err.message 或堆栈发给浏览器。
5. 继续把 GEMINI_API_KEY 只放在服务端环境变量，前端任何文件都不得出现密钥。
6. 给 JSON body 按路由设置更小的体积上限：文本类 256kb，带 base64 图片/音频的接口最多 8mb，并校验 mime 和时长。

## 2. 模型不要写死
请不要把模型名称写死在代码里。
1. 在 .env.example 增加 GEMINI_TEXT_MODEL、GEMINI_TTS_MODEL、VEO_MODEL，默认用当前公开稳定的型号，不要用只有 AI Studio 内部才认识的 ID。
2. server.ts 里所有 generateContent / TTS / Veo 调用改为读取这些环境变量。
3. 如果主模型调用失败（404 或 model not found），自动回退到备用文本模型，并在接口返回里带上 usedModel。
4. 把 getGeminiClient、文案生成、TTS、Veo 拆成独立模块，避免把所有逻辑堆在 server.ts。

## 3. 数字人口播模块
把「数字人口播」做成 ClipFlow 的一个新模块，不要另起项目：
1. 顶部导航增加「数字人口播」页：上传 1 张正脸照片（可在浏览器本地保存多个形象）→ 输入主题，用 Gemini 生成口播稿（前 2 秒必须是钩子句，用户可改）→ 用 Gemini TTS 配音（可选音色、可试听）→ 用 Veo、以照片为参考图生成 9:16 人物说话视频；超过 8 秒自动分段生成再拼接。
2. Gemini 文案、TTS、Veo 调用全部放在服务端独立模块里，前端只调用 /api/*，密钥不得进前端。
3. 生成好的口播片段自动进入素材库，可拖进多轨时间线的视频轨，配音对齐到配音轨，字幕自动上字幕轨。
4. 支持画中画：数字人缩小放角落，主画面放产品或网站镜头。
5. 导出时增加「AI 生成」标识开关，默认开启，满足抖音标注要求。
6. 生成前显示本次 Veo 大约消耗的秒数/额度；失败的片段可以单独重新生成。
7. 若 Veo 暂不可用，先做出完整 UI 和接口，并在界面提示「视频生成即将接入」，不要放会报错的空按钮。

## 4. 成片质量和宣传合规
请修复自动剪辑和对外宣传相关的问题，不要夸大能力：
1. 调用 /api/auto-edit 时，为每个素材附带 1 张代表性画面的压缩 base64（视频用中间帧），让模型根据真实画面选镜头和写字幕。注意压缩体积。
2. 把界面文案里的「声音克隆」改成「专属音色风格」，并加一行小字说明：这是根据样本分析后的 Gemini 预置音色风格化，不是 1:1 复制真人嗓音。
3. 版权扫描结果加醒目免责声明：「这是 AI 检索评估，不是音频指纹鉴定，不能保证平台过审。」
4. 导出完成后检测文件格式；若不是 H.264 MP4，自动在服务端用 ffmpeg 转码，并提示「已转换为适合抖音/TikTok 上传的 MP4」。
5. 把 InspectorPanel.tsx 按功能拆成子组件（转场、BGM、口播、SFX、版权、降噪），先不要改行为。

## 5. 卖成 SaaS 的基础
为 ClipFlow 补上可以上线收费的最小骨架：
1. 增加邮箱注册/登录（或 Google 登录）。每个用户的项目、素材、数字人形象、音色配置保存到服务端，刷新页面能恢复上次工程。
2. 增加「免费额度 / 专业版」两档：免费用户每天限制自动剪辑次数和 TTS/Veo 秒数；超限时引导升级。计费预留 Stripe 接口，密钥放环境变量。
3. 导出默认 1080×1920、30fps 的 H.264 MP4；Facebook 保留 4:5 选项。
4. 平台预设增加 Instagram Reels（9:16）和小红书（3:4 / 9:16）。
5. 把 package.json 的 name 改成 clipflow，写上版本号和说明。
